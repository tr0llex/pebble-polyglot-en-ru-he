# Языковые ресурсы, которые апстрим выселил

Здесь лежат четыре файла, которые до сентября 2026 года жили в самой прошивке,
в `resources/normal/base/lang/`. Наш конвейер пака читает их как входные данные.

| Файл | Кто читает | Зачем |
|---|---|---|
| `ru_RU/tintin.po` | `apply.py`, `context.py`, `list.py`, `scan.py` | шаблон каталога: откуда берутся msgid и порядок записей |
| `ru_RU/codepoints.json` | `buildfonts.py` | какие символы должны быть в кириллических расширениях шрифтов |
| `ru_RU/lang_map.json` | справочно | порядок шрифтов в паке (сам список живёт в `width.py`) |
| `tintin.pot` | справочно | полный список строк прошивки на момент выселения |

## Почему они здесь, а не в `pebbleos/`

Апстрим удалил их коммитами
[`9f1564205`](https://github.com/coredevices/PebbleOS/commit/9f1564205)
(«i18n: remove externalized language assets and tools») и
[`90dc8ead3`](https://github.com/coredevices/PebbleOS/commit/90dc8ead3)
(«i18n: ship English with installed language pack support»): прошивка теперь
собирается только с английским, а каталоги и инструменты пака переехали в
отдельный репозиторий `pebbleos-translations`. Поддержку **установленных**
паков апстрим сохранил — наш `.pbl` по-прежнему ставится и работает.

Пока файлы лежали в `pebbleos/`, обновление checkout'а до свежего апстрима
молча ломало пять наших инструментов: `buildfonts.py` не находил список
символов, остальные — шаблон каталога. Копия здесь развязывает две вещи,
которые незачем держать связанными: **версию прошивки, которую мы собираем**, и
**набор строк, который мы переводим**.

Файлы взяты из `coredevices/PebbleOS` на коммите `5503dd403` — последнем перед
удалением. Лицензия та же, что у апстрима: Apache-2.0.

## Когда их обновлять

`tintin.po` и `tintin.pot` — это снимок строк прошивки. Апстрим добавляет и
меняет строки дальше, и снимок стареет. Что появилось нового, показывает
сравнение с живыми исходниками:

```bash
python3 tools/l10n/scan-untranslated.py
```

Новый шаблон берётся не отсюда, а из сборки прошивки: с коммита `6bc2af180`
(«build: generate a universal translation catalog») каждая обычная сборка
кладёт полный каталог исходных строк себе в каталог сборки.
